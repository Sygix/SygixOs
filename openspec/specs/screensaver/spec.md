# Capability : screensaver

## Purpose
Screensaver vidéos aériennes type Aerial Apple.

## Requirements
### Requirement : Lecture
- WHEN la TV est inactive THEN rotation de vidéos aériennes (paysages/villes, 4K), enchaînement fluide, cache local

### Requirement : Configuration
- Activable/désactivable et horaire réglable depuis Settings
